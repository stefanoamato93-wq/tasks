      Siri setup

      Crea una password solo per Siri. Il tuo account Google resta lo stesso.

      Shortcut "Aggiungi task" (app Comandi su iPhone):

      1. Chiedi input (Testo), domanda: "Che task?"
      2. Ottieni contenuto dell'URL
        URL:
        Metodo POST, Corpo JSON:
        email = la tua email, password = la password, returnSecureToken = Booleano Sì
      3. Ottieni valore dizionario per la chiave idToken
      4. Testo, con questo contenuto (metti la variabile "Input fornito" al posto di INPUT): 
        {"fields":{"title":{"stringValue":"INPUT"},"done":{"booleanValue":false},"source":{"stringValue":"siri"}}}
      5. Ottieni contenuto dell'URL
        URL:
        Metodo POST. Intestazioni: Authorization = Bearer + "Valore dizionario", Content-Type = application/json.
        Corpo: File = "Testo"

      Poi di' "Ehi Siri, aggiungi task".
